## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* VS Code or Android Studio

### Clone the repository

```bash
git clone https://github.com/TheboyArjon/portfolio_app.git
```

### Navigate to the project

```bash
cd portfolio_app
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```

### Build for Web

```bash
flutter build web
```
